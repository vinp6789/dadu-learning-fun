A touch-friendly learning app for toddlers that teaches English and Marathi
letters, phonics, numbers, words and reading.

- **One self-contained `index.html`**: no build step, no framework, no third-party scripts and no tracking
- **Mobile-first**: large tap targets, no accidental text selection, full-screen layout
- **Easy to host**: open the file directly or serve it from any static host (GitHub Pages, Nginx, a Raspberry Pi)

## Run

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080   # then visit http://localhost:8080
```
